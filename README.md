# H² Mobile Mechanics

Upload index.html, pricing.html, style.css, script.js and the images folder to the existing GitHub Pages publishing folder. Replace files of the same name. The ZIP has no enclosing folder. Keep any existing CNAME file for your custom domain.

Both pages use relative links, suitable for repository GitHub Pages sites. No build step or dependencies are required. WhatsApp opens a prefilled quote request; phone and email links open the visitor's apps.

The complete supplied logo is included unchanged. It scales proportionally with height:auto and object-fit:contain.
